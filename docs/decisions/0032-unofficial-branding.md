# 0032. 학교 로고 제거와 비공식 안내

- 상태: 채택 (2026-11-19, 사용자 요청)
- 관련: [0007](0007-scope-smu-cheonan.md)(학교 UI 사용), [0018](0018-user-facing-copy.md)(화면 문구), [0030](0030-pwa-app-wrap.md)(아이콘)

## 맥락

공과대학교학팀에서 공식 홈페이지가 아니니 상명대학교 로고를 빼 달라고 연락했다. 0007에서 학교 로고(시그니처)를 상단 메뉴에, 0030에서 로고 마크를 잘라 앱·탭 아이콘으로 썼다.

## 결정

- 상단 메뉴: 로고 이미지를 빼고 학사모 선 그림(아이콘과 같은 좌표, 인라인 SVG) + '학점플래너'를 둔다. 글자만 두니 심심하다는 사용자 의견으로 그림을 더했다. `public/logo.jpg` 삭제.
- 하단: 이용안내 옆에 "졸업요건 판정은 학교 공식 판정이 아닙니다. 졸업 사정은 학과 사무실과 샘물에서 확인해 주세요."를 둔다. 학교가 요청한 안내라 0018의 이용 정보로 본다. 휴대폰에서 단어 중간에 줄이 바뀌지 않게 `word-break: keep-all`.
- 아이콘(탭·PWA·Android·iOS·스플래시): 로고 마크 대신 학사모 선 그림 + '학점플래너'(남색 `#0E207F` 바탕, 흰 선). 사용자가 보여 준 학교 모바일 학생증 앱 아이콘(선 그림 + 이름)을 참고했고, "상명대학교" 글자는 공식 앱으로 보일 수 있어 넣지 않았다. 48px 탭 아이콘은 글자가 안 읽혀 그림만 둔다. 글꼴은 맑은 고딕 Bold, 생성 스크립트는 저장소 밖(일회성).
- README 캡처(`docs/images`)를 로고 없는 화면으로 다시 찍는다.

## 유지

- 홈 배경 캠퍼스 사진(`public/campus.jpg`): 사용자 결정으로 둔다.
- 전용색 `#0E207F`: 로고가 아니라 화면 색이라 둔다.
