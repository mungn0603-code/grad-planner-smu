# 0015. 대시보드 화면 구성: 상태별 목록과 숫자 하나

- 상태: 채택 (2026-10-24, 사용자 요청 "대쉬보드 구성이 너무 AI가 만든 것 같다")
- 관련: `src/pages.tsx` `Page`·`ResultPage`·`ResultCard`·`PlanPage`·`RecordPage`, `src/styles.css`

## 맥락

학점 계산기는 요건마다 크기가 같은 카드를 격자로 늘어놓았다. 카드 위에는 4px 색 띠(빨강·초록·파랑)를 두르고 그림자를 깔았으며, 카드마다 큰 숫자와 진행 막대를 넣었다. 졸업까지 남은 학점은 접힌 요약 상자 안에 있었다. 모든 화면에는 사진 배너를 깔았다.

## 결정

- 학점 계산기 위에는 "졸업까지 N학점 남음" 숫자 하나와 막대 하나만 둔다. 요건 개수(부족·입력 필요·충족)와 학점 플래너 이동 버튼을 같이 둔다. 전공·교양 밖 일반 학점은 총 학점 옆에 한 마디로 적고, 확인할 점은 그 아래 접힌 칸으로 옮긴다.
- 요건은 카드 격자 대신 한 줄짜리 목록으로 보인다. 순서는 부족(`ok === false`) → 입력 필요(`ok === null`) → 충족(`ok === true`)이다. 부족 안에서는 학점 요건을 남은 학점이 많은 순으로 먼저 놓는다. 진로 트랙(SM-CDR)은 졸업 필수가 아니므로 맨 아래에 따로 둔다.
- 인정 기준 설명(basis·지금)은 행에서 빼서 펼친 내용 맨 위로 옮긴다.
- 화면 면은 흰 바탕과 1px 선으로 나눈다. 그림자와 색 띠는 없앤다. 강조색은 SM Blue 하나만 쓰고, 상태는 6px 점과 짧은 글자로 나타낸다. 빨강은 부족 점과 경고 왼쪽 선에만 쓴다.
- 같은 정보를 두 번 보이지 않는다(2026-10-24 추가). 펼친 요건에서 요건 이름·값·상태를 다시 그리지 않는다. 들은 과목은 '들어간 과목'에만, 관련 과목 표에는 아직 안 들은 과목만 둔다. 하위 항목이 있는 요건의 인정 기준에는 하위 항목 이름 대신 몇 개를 채워야 하는지만 적는다. 요약 상자에서 요건 행과 겹치는 학점 구성(전공·교양)과 평점은 뺀다.
- 과목 목록은 접어 둔다. 요건의 들어간 과목·안 들은 과목·추천 과목은 각각 토글이다. 이수 현황은 이번 학기와 이수 예정 과목이 있는 학기만, 학점 플래너는 다음 학기만 펼친 채로 시작한다.
- 사진 배너는 홈에만 남긴다. 나머지 화면은 흰 제목 줄로 바꾼다.
- 학점 플래너는 결론(못 채우는 요건 또는 모두 충족)을 학기 목록 위로 올리고, 표시 설명은 접는다. 이수 현황은 기본 상태인 '이수' 칩을 빼고 수강 중·이수 예정·제외만 표시한다.

## 남은 확인

- 학생 몇 명에게 첫 화면에서 졸업까지 남은 학점과 부족한 요건을 찾는 데 걸리는 시간을 재 본다. 실측 근거는 아직 없다.
