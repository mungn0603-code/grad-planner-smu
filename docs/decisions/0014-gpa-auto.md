# 0014. 평점평균 자동 계산

- 상태: 채택 (2026-10-22, 사용자 요청 "성적을 가져오니 평점평균도 알아서 산출"). 환산표 밖 규칙(P/NP·재수강 F)은 학칙 원문 확인 전 임시 기준
- 관련: `engine/audit.ts` `gpa`·`audit`, `engine/types.ts` `Policy.gpa`, `data/smu-cheonan/rules.json` `policy.gpa`, `etl/smu-cheonan/migrate.ts` `GPA`, `engine/v6.gpa.test.ts`, `src/pages.tsx` 이수 현황·학점 계산기

## 맥락

'평점평균 1.7 이상' 요건은 학생이 직접 넣는 값(`checks.gpa`)이었다. 샘물 가져오기는 과목별 성적(`GRD_NM`)을 이미 가져오므로 평점평균을 계산할 수 있다.

## 근거

| 항목 | 근거 | 확인 정도 |
|---|---|---|
| 4.5 만점 | 이전 앱(`oracle/legacy/index.publish.html`) '평점평균(4.5 만점)' | 이전 앱 표기 |
| 등급별 평점 A+ 4.5, A 4.0, B+ 3.5, B 3.0, C+ 2.5, C 2.0, D+ 1.5, D 1.0, F 0 | 상명대 학점교류 안내(2025학년도 제1학기, 학사에 관한 규정 제26조 언급) 등급별 환산 표. 다른 대학 사이트에 올라온 PDF(ai.konkuk.ac.kr/sites/filedb/down/haksa/2024/SM_0122.pdf)로 표 값은 확인. 문서 제목은 글꼴 문제로 추출 불가 | 표 값 확인, 출처 문서명은 검색 요약 기준 |
| P·NP 등 등급 없는 성적은 평점에서 뺀다 | 일반 관행 | 학칙 원문 미확인 |
| 재수강하면 이전 기록을 뺀다(F 포함) | 엔진의 재수강 규칙(`policy.retake: latest`)과 맞춤 | 학칙 원문 미확인 |

## 결정

- 대학 데이터 `policy.gpa = { check, scale }`에 환산표를 둔다. 엔진은 대학을 모른다(0001).
- `audit`가 성적으로 평점평균을 계산해 `checks[check]`에 넣는다. 계산값이 직접 넣은 값보다 우선한다. 성적이 하나도 없으면 직접 넣은 값을 쓴다.
- 전체 평점: 학점 가중 평균. 계획 과목, 재수강 이전 기록, 중복 과목, 0학점 과목은 뺀다. F는 나중에 같은 과목을 다시 들었으면 뺀다.
- 학기 평점: 그 학기 성적 그대로(F 포함, 재수강 여부와 무관).
- 화면에는 소수 둘째 자리까지 반올림해 보인다. 요건 판정은 반올림하지 않은 값으로 한다.
- 성적으로 계산했으면 평점 입력 칸을 감춘다.

## 남은 확인

- 학칙·학사에 관한 규정 원문으로 P/NP 처리, 재수강 성적 처리(최고 성적 제한 등), 평점 반올림·절사 규칙을 확인한다. 다르면 `engine/audit.ts` `gpa`만 고친다.
