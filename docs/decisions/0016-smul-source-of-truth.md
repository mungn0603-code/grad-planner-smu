# 0016. 학생 기록은 샘물 값을 정답으로, 미확인·카탈로그 대조 표시 제거

- 상태: 채택 (2026-10-27, 사용자 결정 "샘물에 있는 정보가 가장 정확하다. 학교 공식 인증이니")
- 관련: `engine/audit.ts` `resolve`, `engine/types.ts` `Rule`·`Result`, `src/pages.tsx` `Node`·`Preview`, `src/paste.ts`, `etl/smu-cheonan/migrate.ts`, `data/*/rules.json`, [`ARCHITECTURE.md` §8·§12](../ARCHITECTURE.md)

## 맥락

V44에서 옮긴 데이터에는 근거가 약한 기준을 `unverified`로 표시해 학점 계산기에 '미확인 기준' 칩을 띄웠다. 또 학생 과목의 학수번호가 카탈로그에 없으면 '미등록 학수번호'로 경고했고, 가져오기 확인 화면은 학수번호 없는 행을 카탈로그 과목명으로 채웠다(붙여넣기·시간표 시절의 기능).

지금 입력 경로는 샘물 가져오기·과목 검색·직접 입력뿐이다. 샘물은 과목마다 학수번호·이수구분·학점을 주고, 이수구분은 이미 샘물 값이 카탈로그보다 우선한다(2026-10-22, §12 이전 기록).

## 결정

- 학생 기록(과목·학수번호·이수구분·학점·성적)은 샘물 값을 정답으로 본다. 카탈로그와 맞지 않아도 경고하지 않고 샘물 값으로 센다.
- `unverified` 필드와 '미확인 기준' 표시, '미등록 학수번호' 경고, `fillCodes`(과목명으로 학수번호 채우기)를 지운다.
- 앱이 직접 가진 값은 졸업 기준뿐이다. 매년 3월 1일 그 해 입학 학번 기준을 넣는다(ARCHITECTURE §5).

## 근거

- 샘물은 학교 공식 학사 시스템이다. 이수구분은 수강 당시 학교가 기록한 값이고, 카탈로그는 V44 사본이라 더 오래됐다.
- 실사용 대조: 사용자 동기들 기록으로 문제 없음(사용자 확인, 값은 기록하지 않음). 2022학번 1명은 샘물 학점이수상황표 이수구분별 합계와 앱 합계가 모두 같았다(2026-10-22).
- 샘물 응답의 이수 기록·수강 중 과목은 모두 `SBJ_NO`가 있다(`api/smul.ts` `toRows`).

## 남긴 것

| 기능 | 남긴 이유 |
|---|---|
| 카탈로그 | 학점 플래너 추천, '아직 안 들은 관련 과목', 과목 검색에 필요 |

## 갱신(2026-10-27): 학적·졸업 학점 기준도 샘물

- 사용자 결정: "표시되는 정보 전부 샘물에서 가져온 정보만 활용한다. 샘물 기준으로 계산하고 이것은 학교 공식 인증이다."
- 입학구분·다전공(2~4전공·부전공·연계·융합)·마이크로전공·유학생 여부·전적대학 인정학점을 샘물에서 받고, 이수 형태·입학 유형·학생 유형은 그 값으로 정한다(학생이 고치지 않음).
- 졸업·전공·전공심화·교양·다전공 학점 기준은 샘물 학점이수상황표의 학생별 졸업 기준학점으로 덮어쓴다(`Profile.vars`). 편입생 기준도 이렇게 들어온다.
- 위 표의 `ok:null` 서술과 달리, 상명 데이터는 편입생에게 신입 세트를 그대로 썼다(세트에 입학 조건이 비어 모두에게 맞음). 이제 편입생에게 신입 세트를 쓸 때 교양 필수 영역(`policy.transferUnknown`)은 확인 필요로 둔다.
- 앱 데이터로 남은 기준: 교양 필수 영역의 과목·영역 조건, 평점 1.7, 포트폴리오, SM-CDR 기준. 근거·확인 불가 목록은 ARCHITECTURE §12.

## 한계

- 편입생·다전공 학생 실사용 대조는 아직이다(사용자가 진행 예정).
- 졸업 기준값 자체(필요 학점·SM-CDR 3/30/2/1)의 정확성은 실사용 대조한 학과·학번에서만 확인됐다.

## 갱신(2026-10-29): 교양 영역도 샘물 교양영역으로

- 문제: 판정은 카탈로그 영역만 썼다. 카탈로그(2026 교양 목록)에서 없어진 과목은 영역이 비어 핵심역량·균형교양에 안 잡혔다. 사용자 동기(2022학번) 기록에서 `인간과시간`(샘물 `핵심(윤리실천역량)`)·`물리현상의이해`(샘물 `균형(자연)`)가 빠져 샘물은 충족, 앱은 1과목·1영역 부족으로 나왔다.
- 결정: 영역은 직접 고친 값(`area`) → 샘물 이수 당시 교양영역(`cultArea`, `CULT_ARA_NM`) → 카탈로그 순으로 정한다. 대응은 `rules.json` `cultAreas`(정규식 → `areas` 키, `etl/smu-cheonan/migrate.ts`에서 생성): `기초(…)`·`핵심(…)`·`일반(…)`, `균형(인문|사회|자연|공학|예술|브리지)`, 교양이 아니면 `*` → 해당 없음.
- 대응 없는 이름(예: 타대 계절 `균형교양`)은 카탈로그 영역을 쓴다.
- 확인: `균형(사회)`·`핵심(…)`·`기초(…)`·`일반(…)`·`*`은 배포 로그(`ARCHITECTURE.md` 배포본 확인 기록), `균형(인문)`·`균형(자연)`은 동기의 샘물 학점이수상황표 화면(`(균형)균형(자연)` 꼴). `균형(공학|예술|브리지)`는 같은 꼴로 추정, 실제 값 확인 불가.
