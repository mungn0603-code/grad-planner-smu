# 0034. 사용조사 피드백 반영: 이수구분 코드표·교필 영역 이름·밀어서 담기/빼기

## 맥락

사용조사(2026-11-10~18, 62명)에서 학점 집계 오류와 조작 불편이 나왔다.

- 다전공 응답자 2명: 2전심 과목이 전공 학점에 안 들어감. 원인: 이수구분 표가 학교 정정 안내 코드(0017)만 갖고 있어 `2전심`이 없었다. 표에 없는 이수구분 과목은 졸업 학점에만 들어간다.
- 과목명이 바뀐 교양필수(알고리즘 과목)·재수강 과목이 안 들은 것으로 나옴. 원인: 교양필수 칸 일부가 과목명 목록으로 맞춘다.
- 이수 예정 과목 삭제 버튼을 찾기 어려움(2명), 학기별 과목 수정 불가(1명).
- '확인할 점'의 뜻을 모르겠음(1명). 화면에 설명 문구가 많다는 사용자 판단.

## 결정

1. 이수구분 표를 샘물 코드표 48개 전부로 넓힌다. 2·3·4전공 코드와 `복필`·`복선`은 다전공(`m2.dept`), 부전공 코드는 `m2.minor`, `1전필`·`1학기`는 주전공, `교기`는 교양, 교직 코드는 교직. 테스트(`engine/v12.smul-cats.test.ts`)가 48개가 다 있는지 본다.
2. 과목명은 샘물 값 그대로 보인다(이미 그렇다). 교양필수 칸은 과목명 또는 샘물 교양영역 괄호 안 이름으로 맞춘다. 과목명이 바뀌어도 학교가 붙인 영역으로 들어간다.
3. 과목 줄을 왼쪽으로 밀면 버튼 하나: 플래너 추천 과목은 '담기', 담은 과목은 '빼기'. 같은 동작은 줄을 눌러 여는 칸에도 둔다. 이수 예정 과목은 그 칸에서 학기를 바꾼다. 이번 학기 수강 중 과목은 샘물 기록이라 빼기·학기 변경을 두지 않는다. 이수 현황에서 밀어서 빼기는 이수 예정 과목만(이수한 기록은 눌러서 연 칸의 삭제만).
4. '확인할 점'은 '샘물과 다른 학점'으로 바꾸고 샘물 대조 결과만 보인다. 엔진 경고(표에 없는 이수구분 등)는 개발자 콘솔로만. 설명 문장은 지우거나 한 줄로 줄인다(0018).

## 근거

- 이수구분·영역 이름: 샘물 화면 데이터(측정), 0016(샘물 값이 정답).
- 밀기: NN/g "Contextual Swipe" — 밀기는 삭제·제거 같은 동작에 쓰고, 보이는 단서가 없으면 못 찾으니 다른 길도 둔다. eBay Playbook List — 밀기 동작만으로 기능에 닿게 하지 않는다. 사용자 결정(담긴 과목은 빼기, 안 담긴 과목은 담기).

## 검토한 대안

| 대안 | 채택하지 않은 이유 |
|---|---|
| 담은 과목 오른쪽에 항상 보이는 ✕ 버튼 | 사용자가 밀기를 골랐다. 눌러서 여는 칸의 '빼기'가 보이는 길을 대신한다 |
| 이수구분 이름을 정규식(앞 숫자·뒤 글자)으로 해석 | 코드표가 48개로 닫혀 있어 그대로 적는 편이 읽기 쉽다 |
| 과목명 대응표(옛 이름 → 새 이름)를 손으로 관리 | 샘물 영역 이름으로 풀리고, 해마다 바뀌는 이름을 따라갈 필요가 없다 |
| 전공 카드와 전공심화 카드를 합쳐 보이기 | 사용자 판단: 전공 남은 학점과 그 안의 전공심화 남은 학점은 따로 보이는 게 맞다 |
